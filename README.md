# 🏐 Volley Tracker

Εφαρμογή στατιστικών αγώνα βόλι — **PWA** ( Progressive Web App) στα ελληνικά.
Λειτουργεί στο κινητό σου στο γήπεδο, **offline**, χωρίς λογαριασμό και χωρίς διαφημίσεις.

Τα τι μπαίνουν: **χτυπήματα, υποδοχές, πάσες, σερβίς** — γρήγορα, με 2 πατήματα ανά στατ.

---

## Τι μπορεί να καταγράψει

| Κατηγορία | Επιλογές |
|---|---|
| **Χτυπήματα (καρφιά)** | `Tip` · `Spike`, και για κάθε είδος: `Point` · `Saved` · `Blocked Saved` · `Blocked` · `Out/Net` |
| **Υποδοχές** | Μόνο **Τύπος υποδοχής**: `0` `1` `2` `3` (πατάς τον τύπο = καταχωρείται) |
| **Πάσες** | Σε ποιον: `MB` · `OH` · `OPP` · `S` — Πρόβλημα: `Χαλιά χρόνια με MB` · `Πολύ κοντά στο δίχτυ` · `Πολύ μακριά` · `Πολύ μέσα` · `Εκτός αντένας` · `Πολύ ψηλά` (πολλαπλή επιλογή) |
| **Σερβίς** | Τύπος: `Άλμα` · `Float` — Αποτέλεσμα: `Ace` · `Out` · `Σώθηκε` — προαιρετικά ζώνη `1-6, 9` |

Επιπλέον: ταμπλό σκορο ανά σετ, timeouts, ενδέκη ανά σετ, αλλαγές παικτών, ιστορικό καταχωρήσεων με επεξεργασία/διαγραφή, Undo.

Το πεδίο **«Δική μας ομάδα»** έρχεται ήδη γεμάτο με `ΕΘΝΙΚΟΣ Γ.Σ` (αλλάζεται αν θέλεις).
Η λίστα είναι στο `js/config.js` (`DEFAULT_TEAM`, `DEFAULT_ROSTER`).

## Οθόνη Γηπέδου (κύρια)

Η πρώτη καρτέλα είναι το **γήπεδο** — ένα ηθάνο που ακολουθεί τη ροή του παιχνιδιού:

```
      ┌───────────── TOPBAR ─────────────┐
      │ V  ΕΘΝΙΚΟΣ   Γήπεδο Στατ. Ρόστ. ☰│
      ├────────── SCORE RIBBON ──────────┤
      │ ΕΘΝΙΚΟΣ  −  4  [ΣΕΤ 1]  7  −  ΑΣΤ│
      ├──────── STATUS LINE ─────────────┤
      │ [ΥΠΟΔΟΧΗ] ΕΘΝΙΚΟΣ έχει υποδοχή  │
      ├───────────── ΓΗΠΕΔΟ ─────────────┤  ┌── MATCH LOG ──┐
      │   (4)   (3)   (2)               │  │ ● Γιουλιάνο   │
      │   (5)   (6)   (1)               │  │   Tip · Point  │
      ├═══════════ φιλέ ═══════════════┤  │ ● Βασίλης     │
      │  (OH)  (MB)  (OPP)              │  │   Άλμα · Ace   │
      │  (L)   (S)   (OH) ●             │  │ ● Τάσος      │
      └─────────────────────────────────┘  │   Υποδοχή 3    │
      [ Άμυνα ] [⇄ Libero] [⇄ MB] [Περ.] │ ├────────────────┤
      [ Σετ 1 ] [ Ενδέκη ] [ Ρύθμιση ]   │ │ ΣΗΜΕΙΩΣΗ      │
                                         │ │ [__________]  │
```

### Ξεκίνημα σετ

Πατάς **«Ξεκίνα το σετ»** και διαλέγεις **σε ποια ζώνη (1-6) είναι ο παίκτης σερβίς**.
Θεωρούμε ότι σερβίρει η δική μας ομάδα. Ζώνη 1 = πίσω δεξιά, από όπου σερβίρει —
οι υπόλοιπες 5 θέσεις μπαίνουν μόνες τους.

### Ζώνες

| Ζώνη | Θέση |
|---|---|
| 1 | πίσω δεξιά (ο σερβιέρ) |
| 2 | μπροστά δεξιά |
| 3 | μπροστά μέση |
| 4 | μπροστά αριστερά |
| 5 | πίσω αριστερά |
| 6 | πίσω μέση |

### Ροή του rally

**Σερβίρουν αυτοί (έχουμε υποδοχή):**

1. Πατάς τον παίκτη που υπέδεξε → παράθυρο **υποδοχής 0/1/2/3**
2. Πατάς τον παίκτη που χτύπησε → ο παίκτης σερβίς **βαθμολογεί την πάσα** (σε ποιον + πρόβλημα)
3. Ανοίγει αμέσως το παράθυρο του χτυπήματος → **Tip / Spike** + αποτέλεσμα

**Σερβίρουμε εμείς:** πατάς τον σερβιέρ → Άλμα / Float και **Ace / Out / Difficult / Σώθηκε**.

### Περιστροφή

Μόλις η ομάδα κερδίσει το σερβίς (side-out), οι φούσκες **περιστρέφονται αυτόματα**
δεξιόστροφα (ο παίκτης της ζώνης *n* πάει στη *n-1*, ο παίκτης σερβίς από τη 2 στη 1).
Ισχύει και αν αλλάξεις το σκορ χειροκίνητα με το **+**.

### Ο κανόνας του κεντρικού και του λιμπέρω

Στο βόλι ο κεντρικός **δεν παίζει πίσω** — εκτός από τη **ζώνη 1**, από όπου
σερβίρει. Η εφαρμογή το τηρεί μόνη της:

- Μόλις η θέση του κεντρικού πέσει στη ζώνη 1, **μένει εκεί και σερβίρει ο ίδιος**
- Στη θέση που πήγε ο λιμπέρω μπαίνει **ο δεύτερος κεντρικός** (μπροστά)
- **Ο λιμπέρω βγαίνει από το γήπεδο** — παίζουμε δύο κεντρικούς, χωρίς λιμπέρω
- Στην επόμενη περιστροφή ο κεντρικός ξαναβγαίνει μπροστά και **ο λιμπέρω
  επιστρέφει** στη θέση του

Αν κάποτε δεις λάθος στήση (π.χ. με χειροκίνητη αλλαγή), πατάεις **«Ρύθμιση σετ»**
— η εφαρμογή διορθώνει μόνη της τη σειρά.

Τα γρήγορα κουμπιά **⇄ L** / **⇄ MB** αλλάζουν *ποιος* παίζει σε αυτές τις
δύο θέσεις. Όταν δεν υπάρχει τι να αλλαγή (και οι δύο κεντρικοί παίζουν, ή ο
λιμπέρω είναι εκτός), σου λέει ποιος είναι η αιτία.

### Σερβίς

Σερβίρει **πάντα ο παίκτης της ζώνης 1**. Αν πατήσεις κάποιον άλλον, η εφαρμογή
δεν ανοίγει παράθυρο — σου λέει ποιος είναι ο σερβιέρ.

### Κάτω από το γήπεδο

- **Άμυνα** → πατάς το κουμπί, μετά τον παίκτη που έκανε την άμυνα, και βαθμολογείς **0-3**
- **⇄ L** / **⇄ MB** → γρήγορη εναλλαγή λιμπέρω / μεσικών, χωρίς να μπερδεύονται τα στατιστικά
- **MATCH LOG** (δεξιά στήλη) → η ροή του αγώνα με χρώμα ανά κατηγορία, και από κάτω το πλαίσιο **Γρήγορη σημείωση** (βρίσκεται και στα **Στατιστικά → Σημειώσεις**)
- **Ρύθμιση σετ** → άλλαξε ποιος σερβίρει ή πού είναι ο παίκτης σερβίς

## Διάταξη του UI

Τρεις προβολές στην πάνω μπάρα, όλα τα υπόλοιπα στο **☰**:

| Προβολή | Τι βλέπεις |
|---|---|
| **Γήπεδο** | Ταμπλό, γήπεδο με τις 6 φούσκες, γρήγορες ενέργειες, και δίπλα το **MATCH LOG** με το ροή του αγώνα |
| **Στατιστικά** | Κάρτες: Συνοπτικά, Χτυπήματα, Υποδοχές, Πάσες, Σερβίς, Άμυνα, Σημειώσεις, Σετ ανά σετ, πίνακας παικτών, λογόδιο |
| **Ρόστερ** | Όλοι οι παίκτες με αριθμό και θέση · πράσινοι αυτοί που είναι στο γήπεδο · προσθήκη/διαγραφή |

**Διάταξη:** σε υπολογιστή το γήπεδο και το MATCH LOG είναι δίπλα (δύο στήλες).
Στο κινητό το λογόδιο πέφτει κάτω από το γήπεδο — ίδια εικόνα και από τα δύο.

**Θέμα:** σκούρο φόντο (#080c11) με λάμπινο-πράσινο (#c9f31d) για τις ενεργές
καταστάσεις και ουρανό-γαλάζιο (#38bdf8) για τις εισόδους.

**Το γήπεδο** είναι ξύλινο, όπως στην αληθινή πράξη: ζεστό κορτί με λεπτές
σανίδες, λευκές γραμμές (πλάϊ-άκρες, γραμμές τέλους και **attack line** 3 μέτρα
από τη φιλέ), και φιλέ με σκούρο πλέγμα, λευκές ταινίες πάνω-κάτω και λευκές
αντέννες στα άκρα. Η αντίπαλη πλευρά είναι λίγο πιο σκούρα από τη δική μας.

## Καταχώρηση στατιστικών

| Κατηγορία | Επιλογές |
|---|---|
| Χτυπήματα | Tip / Spike → Point · Saved · Blocked Saved · Blocked · Out / Net |
| Υποδοχές | τύπος 0 / 1 / 2 / 3 (0 = χωρίς μπλόκ) |
| Πάσες | σε ποιον πήγε + τυχόν πρόβλημα |
| Σερβίς | Άλμα / Float → Ace · Out · **Difficult** · Σώθηκε |
| Άμυνα | 0 / 1 / 2 / 3 |
| Σημειώσεις | ελεύθερο κείμενο |

Αν προτιμάς τον παλιό τρόπο (μία-μία αντί για πάτημα στο γήπεδο), πήγαι
**☰ → Χειροκίνητη καταχώρηση** και διάλεξε **Χτυπήματα · Υποδοχές · Πάσες · Σερβίς**.

## Αυτόματο σκορ

Το σκορ **μαθαίνεται μόνο του** από τα στατιστικά — δεν χρειάζεται να το πατάς:

| Γεγονός | Πόντος | Ροή |
|---|---|---|
| Χτύπημα `Point` | **+1 εμείς** | τελειώνει |
| Σερβίς `Ace` | **+1 εμείς** | τελειώνει |
| Χτύπημα `Blocked` ή `Out / Net` | **+1 αντίπαλοι** | τελειώνει |
| Σερβίς `Out` | **+1 αντίπαλοι** | τελειώνει |
| Υποδοχή τύπος `0` | **+1 αντίπαλοι** | τελειώνει |
| Άμυνα `0` (δεν τη διάσωσε) | **+1 αντίπαλοι** | τελειώνει |
| Χτύπημα `Saved` ή `Blocked Saved` | *κανένας* | **ετοιμαζόμαστε για επίθεση** |
| Άμυνα `1` / `2` / `3` (τη σώσαμε) | *κανένας* | **ετοιμαζόμαστε για επίθεση** |
| Υποδοχή `1/2/3` · Σερβίς `Difficult` / `Σώθηκε` | *κανένας* | ελεύθερη συνέχεια |

Μπορείς να το **κλείσεις** από ☰ → *Αυτόματο σκορ* και να βάζεις το σκορ χειροκίνητα με τα `+` / `−`.

Το **Undo** σε κάθε μήνυμα επαναφέρει όχι μόνο την καταχώρηση αλλά
**ολόκληρη την κατάσταση του σετ**: σκορ, ποιος σερβίρει και την περιστροφή.
Έτσι αν πατήσεις λάθος παίκτη ή λάθος αποτέλεσμα, το Undo σε φέρνει
πίσω ακριβώς εκεί που ήσουν.

### ✏ Διόρθωση καταχώρησης

Πάτα **οποιαδήποτε γραμμή** στο MATCH LOG (δεξιά στήλη) για να την
επεξεργαστείς: άλλαξε παίκτη, αποτέλεσμα ή σετ. Αν η αλλαγή επηρεάζει
τον πόντο (π.χ. αλλάζεις ένα `Point` σε `Blocked`), **το σκόρ
διορθώνεται αυτόματα** ώστε να μην μείνει ασυνέπειο με τα στατιστικά.
Υπάρχει και κουμπί **Διαγραφή** μέσα στο ίδιο παράθυρο.

## Τύπος υποδοχής (0 / 1 / 2 / 3)

Δείχνει **πόσοι μπλόκερ έχουν ανέβει ψηλά** η αντίπαλη ομάδα, άρα σε ποιον μπορεί να πάει η πάσα:

| Τύπος | Κατάσταση | Επιλογές |
|---|---|---|
| **0** | Κανένας μπλόκ ψηλά | Ελεύθερη επιλογή |
| **1** | Μονομπλόκ | Μόνο **OH** |
| **2** | Διμπλόκ | **OH ή OPP** (αποφεύγεις τη ραφή) |
| **3** | Τριμπλόκ (full block) | **OH, OPP, MB** (ο MB είναι ανοιχτός) |

Στην καρτέλα **Υποδοχές** πατάς παίκτη και μετά τον τύπο — **η καταχώρηση γίνεται αμέσως** (2 πατήματα).

## Ρόστερ ομάδας

Το ρόστερ έχει ήδη τους **15 παίκτες** με τις θέσεις τους:

| Θέση | Παίκτες |
|---|---|
| **L** | Τασος, Ραφ |
| **S** | Βασιλης, Δημητρης |
| **MB** | Αποστολοσ, Νικος, Αντωνης, Φιλλιπος |
| **OH** | Γιουλιανο, Μητσοβαγγελος, Τσοτσονις, Σαββας, Κοσμας, Κωνσταντινος Κουτσουραδης, Αντρεας Κολλιας |
| **OPP** | Νικος, Τσοτσονις, Αντρεας Κολλιας, Κοσμας, Κωνσταντινος Κουτσουραδης |

- Υπάρχουν **από την αρχή κάθε αγώνα**, αλλά **μπορείς να τους διαγράψεις ελεύθερα** — δεν έρχονται όλοι σε κάθε αγώνα.
- Μπορείς να **προσθέσεις** όσους άλλους θέλεις και να **διαγράψεις** όποιον θέλεις.
- Η **θέση** κάθε παίκτη αλλάζει απευθείας από το dropdown στη λίστα.
- Η ενδέκη **γεμίζει αυτόματα** από τις θέσεις — πατάς **⚡ Αυτόματη εισαγωγή**. Αν διαγράψεις παίκτη, αντιστοιχίζεται από τους υπόλοιπους.
- Στην ενδέκη κάθε θέση (S, OH, OPP, MB, L) δείχνει **μόνο τους παίκτες που παίζουν σε αυτή** — π.χ. στο `L` βλέπεις μόνο Τάσο και Ραφ. Ο αριθμός δίπλα στη θέση δείχνει πόσοι ταιριάζουν.

> Για να αλλάξεις κάτι στη λίστα (π.χ. να βγάλεις παίκτη ή να διορθώσεις θέση), άλλαξε το `DEFAULT_ROSTER` στο `js/config.js`.

## Γρήγορη καταχώρηση

1. **Πάτα παίκτη** (πάνω).
2. **Πάτα αποτέλεσμα**.

Το «Τύπος σερβίς» **μένει επιλεγμένο** — το αλλάζεις μόνο όταν χρειάζεται.
Κάθε καταχώρηση έχει **Undo** στο μήνυμα που εμφανίζεται.

### 🔄 Swap MB / Λιμπέρω
Σε κάθε αγώνα υπάρχουν δύο MB και δύο Λιμπέρω. Το κουμπί **⇄ MB** και **⇄ L** δείχνει/αλλάζει ποιος είναι ενεργός.
Τα στατιστικά **δεν μπερδεύονται ποτέ** — κάθε γεγονός αποθηκεύεται με το συγκεκριμένο παίκτη, όχι με τη θέση.

### 💡 Υπενθύμιση πάσας
Μετά από χτύπημα θυμάται ποιος χτύπησε τελευταία και προτείνει αυτόν για την επόμενη πάσα.

## Στατιστικά (ιστορικά)

- **Συνοπτικά**: σετ, πόντοι από χτύπημα, aces, συνολικές υποδοχές, καθαρές πάσες, πρώτος σκόρερ / σερβιέρ / υποδοχέας.
- **Χτυπήματα**: ιστόγραμμα τι είδους ήταν (Tip/Spike), ποιος χτύπησε και πόσοι πόντοι έβαλε, και **για κάθε παίκτη** αναλυτικό ιστόγραμμα τι έκανε σε κάθε χτύπημα (Point · Saved · Blocked Saved · Blocked · Out).
- **Υποδοχές**: ποιος υπέδεξε και πόσες, κατανομή τύπων 0/1/2/3, και **για κάθε παίκτη** αναλυτική ανάλυση τύπων.
- **Πάσες**: ποιος έδωσε πάσα, κατανομή σε MB/OH/OPP, ιστόγραμμα προβλημάτων, πόσο καθαρές ανά παίκτη.
- **Σερβίς**: ποιος πέτυχε ace, άλμα vs float, out vs σώθηκε, και αναλυτικά τι έκανε κάθε σερβιέρ.
- **Σετ ανά σετ**: πίνακας σκορο/χτυπημάτων/υποδοχών/aces **και ποιοι έπαιξαν σε κάθε σετ**.
- Φίλτρο: `Όλα` ή συγκεκριμένο σετ.

## Εξαγωγή & μοίρασμα

Από το **☰ μενού** ή από την αρχική οθόνη:

- **Εξαγωγή αγώνα (`.json`)** — αρχείο JSON με όλο τον αγώνα. Το στέλνεις (e-mail, Drive, Viber, WhatsApp) στο κινητό σου και το εισάγεις από **«Εισαγωγή αγώνα»**.
- **Εξαγωγή CSV** — για Excel: σύνοψη ανά σετ, στατιστικά ανά παίκτη και όλες οι καταχωρήσεις. (Με `;` και BOM, ανοίγει κανονικά στο Excel.)
- **Εξαγωγή όλων (`.json`)** — ολόκληρο backup, με όλους τους αγώνες.

Τα ονόματα αρχείων βγαίνουν χωρίς τόνους (`volley-εθνικος-γσ-vs-ολυμπιακος-2026-10-11.json`)
ώστε να ταξιδεύουν σωστά.

**Αν ο επιλογέας αρχείων του κινητού δεν δείχνει το αρχείο**, άνοιξέ το με οποιοδήποτε
πρόγραμμα, αντίγραψε τα περιεχόμενά του και επικόλλησά τα στο πλαίσιο
«Επικόλληση περιεχομένου» της εισαγωγής.

Τα δεδομένα αποθηκεύονται **τοπικά** στο κινητό (localStorage). Δεν στέλνονται πουθενά.

## Εγκατάσταση

### 🌐 Online (GitHub Pages)

**https://apostolostzo.github.io/Volley_Tracker/**

Άνοιξε το link στο κινητό και εγκατέστησε το στην αρχική:
- **Android Chrome**: μενού ⋮ → *Εγκατάσταση εφαρμογής*
- **iPhone Safari**: Μοιράσου → *Add to Home Screen*

Κάθε push στο `main` κάνει redeploy αυτόματα (GitHub Actions).

### Στο δίκτυο (Wi-Fi)

```bash
npm install
npm start          # http://localhost:8080
```

Άνοιξε τη διεύθυνση στο κινητό (ίδιο Wi-Fi).

> Σημείωση: το service worker χρησιμοποιεί *network-first* για JS/CSS, άρα όταν έχεις internet
> παίρνεις πάντα την πιο φρέσκια έκδοση. Offline πέφτει στην κρυφή cache.

### Αν ενεργοποιείς εσύ το GitHub Pages

Το workflow στο `.github/workflows/deploy.yml` κάνει όλη τη δουλειά, αλλά το GitHub
**δεν επιτρέπει σε workflow να δημιουργήσει μόνο του** το Pages site. Χρειάζεται μία φορά:

**Settings → Pages → Build and deployment → Source → `GitHub Actions`** → Save.

Εναλλακτικά χωρίς Actions: Source → `Deploy from a branch` → `main` / `(root)`.
(Τότε ο ιστότοπος δουλεύει, αλλά το workflow θα βγάζει κόκκινο σε κάθε push.)
